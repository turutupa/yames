## Finding (item 2): with the chart sent, the engine names no chord

`heardChart(jam)` sends the chart whenever the jam's timeline chord names are on (`jam.chords`, on by
default). With a chart the engine takes it as the truth (`harmony/mod.rs` `close_beat`: `chart_chord_at`
instead of the chord path), the key reads "chart", and the summary's `chords` (which never count a chart's
chord, `worker.rs` `Heard::beat`) are empty. So on a default jam there is nothing heard to set beside the
chart, and the line is not said. It is said for a jam played with the timeline's chord names off. Making it
say something on a default jam needs the engine to estimate chords beside the chart: Rust, the harmony
engine, not this leg's.
