**Item 2 of the brief, done differently and why.** The brief had `endSessionNow` call a callback the composer
hands it from `useToolCoach` where it writes the tool coach's summary. Instead `usePracticeHistory` takes the
tool coach's refs and setters as named options (`setMessages`, `narrativeRef`, `gatekeeperRef`,
`speakAndRevealRef`, ...), destructured in its signature, so `startSessionNow` and `endSessionNow` move with
not one character changed and no call between them reordered. A callback would have cut both bodies into
pieces. The `useCallback` deps arrays are the same text over the same values (`maybeSpeak` and
`speakAndReveal` are the tool coach's own memoised functions), so every returned function closes over what it
did and keeps its identity: `startSession`, `endSession` (`[queue]`), `isActive` (`[]`), `handleChipAction`,
`clearMessages`.
