## Shape
- `src/locales/<lang>/toolTips.json`: `toolTips.catalog` (6 vocabularies), `defaultMode`, `proMode`,
  `words` (values for `{direction}`, `{correctionDirection}`, `{change}`). English made by
  `scripts/tool-tips-extract.ts` (one-shot), equal to the old constants (`templateCatalog.data.test.ts`).
- `src/coach/templateCatalog.ts` is a loader: live `TEMPLATE_CATALOG` / `DEFAULT_MODE_CATALOG` /
  `PRO_MODE_CATALOG` read `i18n.language` at every access; `toolTipsLanguage()`, `toolTipWords()`,
  `localizeTipContext()`.
- Pending sections: English text in the locale's file, named in `src/coach/toolTipsPending.json` and in
  `STILL_PENDING` of `src/coach/toolTips.locales.test.ts` (must match). Pending instrument -> locale's
  generic; pending generic -> English; pending overlay/words -> English's.
- `useToolCoach.ts`: rephrase and drill model comment only when `toolTipsLanguage() === "en"`;
  bias context localized; `formatChangeCopy` reads `words.change`.

## Translation flow
1. Helpers write `/tmp/coach-c5c3/i18n/<loc>/<section>.json` (brief `/tmp/coach-c5c3/i18n/HELPER.md`;
   English sections from `node scripts/tool-tips-locales.mjs sections /tmp/coach-c5c3/i18n`).
2. `node scripts/tool-tips-locales.mjs merge /tmp/coach-c5c3/i18n` -> locale files + pending json.
3. Update `STILL_PENDING` in the test; `report 10 <seed>` for a look.
