  chip's selector), `hearBackLabel(stage, bar)`.
- `src/containers/session/hooks/useHearBack.ts` (new): the sequence. Press: `setVoiceHearing(true)`,
  then in the Session's queue `setListenDemo(true)` -> `hearTake(serial, N, N)` -> the gate re-armed

  own end, second press, Start from elsewhere via `soundGate`, leaving the result / the view, unmount):
  `stopHearTake(g)` if one is held, `setPlaying(false)` + `clearSong` if the demo was loaded (not
  when a foreign Start cut it), `liftGate`, `setVoiceHearing(false)`; `active` until the engine
  reports it silent. Asks `heardTake(serial)` at 0, 0.4, 1.2, 2.5, 5 s on a result (the audio is
  moved into the slot a moment after the late grade).
- `session/listenDemo.ts`: `buildListenDemo(take, { bars })`, a range of pattern bars, its length.
- `coach/voice.ts`: `setVoiceHearing` (the take playback path is not `isPlaying`).

## Decisions

- One bar (the note's compared pattern bar), never a range: the chip says "bar N".
- The demo half has the Take's one bar of count-in (the tempo is heard before the bar).
- The chip is added in `ResultNote`, not through `coach/ask/suggest.ts` (an Ask file another leg
  edits). Folding it into the chooser is a follow-up.
