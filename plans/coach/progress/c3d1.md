# Leg c3d1: the router's training data (records, a renderer, the leak test)

Brief: `plans/tasks/coach/c3d-small-router.md`, "The data" items 1-5. No model trained here.

## What is where

- `src/coach/train/intents.ts`: the seed table: 41 call intents, 8 "yours" (the never-list), 10 "none",
  7 card intents (the seven card shapes of `coach-int1`, skipped until `EVAL_CARDS` lists their ids).
- `evals/coach/train/wordings/<lng>.json`: what a player types, per intent, with `{slots}`; written by
  sonnet helpers (en; es+pt-BR; de+nl; fr+it; pl+ru; tr+vi; ja+ko; zh-CN+zh-TW) who were given the
  intents, the command tables and the Path titles, never the held-out set.
- `src/coach/train/generate.ts`: situations (screen, Path/Step, Session phase, grading, tempo), slots
  filled from the app's data (Path / Step / Exercise titles in the language, the command tables' words),
  a shuffled tool list with some withheld, and the answer **from the runner** (`judge`: `effectOf`).
- `src/coach/train/render.ts`: record -> `{prompt, completion}` with the app's `choicePrefix` /
  `choiceContext` / `choiceFactsFor` / `choiceGrammar` and the ChatML of `coach::ask_prompt_head/tail`.
- `src/coach/train/gbnf.ts`: GBNF -> RegExp, so a test holds completions to the grammar.
- `src/coach/train/leakage.ts`: normalised equality / edit distance <= 3, same language.
- `scripts/coach-train.mjs`: `generate`, `render [--check]`, `sample`.
- Tests: `train.test.ts` (unit), `trainData.test.ts` (the committed files: leakage, runner, grammar, counts).

## The data (`evals/coach/train/`, seed 1)

10,500 records: `train.jsonl` 9,975, `validation.jsonl` 525 (5% of every language × kind group, taken in
whole wordings where it can be, so validation mostly holds wordings training never saw). Every language
is the same: **700 = call 280 / which 126 / yours 112 / none 182** (none = 91 not a request + 63 wrong
screen + 28 tool withheld), against the held-out set's 168 / 24 / 24 / 36 of 252. About 47 a language are
relative "faster / slower" requests with no number (weighted three times); about 35 are "already so"
calls (count-in off while it is off: the call is right, the app answers "already"). Per-language counts
and every drop are in `stats.json`.

How an answer is decided (`judge`, the runner via `effectOf`, never a model): accepted (or a door a later
leg wires) -> the call; the name matches several titles -> `which`; refused `notNow.here` / `notNow.take`
-> `none` (wrong screen, a Take running); the tool is not in the list shown -> `none` (withheld);
`notNow.already*` / `following` -> the call (tag `already`); anything else the runner refuses -> dropped;
a query longer than the grammar's 60 characters -> dropped. Never-list intents -> `yours` with the item.

The tool list: all 24 player tools shuffled; 40% of records show all, the rest withhold 1-6 tools (never
the answer's tool, except in the withheld records, where it is withheld on purpose). Withheld tools are
left out of the prefix, the "Tools here" line and the grammar.

Leakage: the generator drops (and counts) every text within an edit distance of 3 of a held-out text in
its language after folding case, punctuation and spaces: 0-29 a language (zh-CN 29: short CJK texts).
`trainData.test.ts` fails the build on any that remain; the held-out hashes are re-checked there and by
`scripts/coach-train.mjs generate`.

Review: one sonnet reviewer per language pair re-read 50 records a language (750): **26 rejected** (de 7,
zh-TW 6, nl 4, zh-CN 4, ja 2, pt-BR 2, vi 1, the rest 0), mostly names cut at a function word ("und",
"über", "e pentatônicas", "Blues và") and three wordings written in English in the nl / zh-TW files. Each
rejected wording is blocked (`review/<lng>.json`), and the name forms now begin and end on content words.
The re-generated set was not re-sampled.

## Commands

```sh
node scripts/coach-train.mjs generate            # records from wordings (queue job; ~2 min)
node scripts/coach-train.mjs render --in evals/coach/train/train.jsonl --out <dir>/train.rendered.jsonl --check
node scripts/coach-train.mjs render --in evals/coach/train/validation.jsonl --out <dir>/validation.rendered.jsonl --check
node scripts/coach-train.mjs sample --lang all --n 50 --out evals/coach/train/review/sample
```

`render` writes `{id, prompt, completion}`: `prompt` ends with the prefilled `<think>\n\n</think>\n\n`,
`completion` is the answer JSON (args in declared order, compact) followed by `<|im_end|>`. It uses the
prompt code of the checkout it runs in, so c3bp's prompt changes flow in by re-rendering.

## Gates (queue jobs, logs via `job logs <name>`)

- tsc: `coach-c3d1-tsc-4` pass (on the final code).
- vitest `src/coach/train src/coach/ask`: `coach-c3d1-vitest-train-3` 14 files, 1008 passed / 11
  skipped (the leak test, the runner/grammar/checkCall test over all 10,500 records, the generator's unit
  tests, and `evalSet.test.ts`: the held-out hashes unchanged).
- build: `coach-c3d1-build` pass (one commit before the last; that commit changed only an intent weight
  table, and tsc and vitest passed after it).
- `render --check` on validation: `coach-c3d1-render` 525 rendered, 0 failing.

## Decisions and open points

- Cards: the seven card intents have wordings in every language and are skipped until `EVAL_CARDS`
  lists their ids; then `generateLanguage(..., {mix: CARD_MIX})` gives them 20% (one table, no code).
- Not generated: `show_bars` (needs a song in the context, which the eval world never has),
  `make_exercise` and `restore_part` (not intents), `set_setting language` (the eval host knows language
  codes only, never a language's name); `open_settings` never targets devices / grading / recording
  (the command tables leave them out: those are the never-list's "show me").
- Fixed world: the jams, presets and followed Paths are the eval world's; a model may learn those names.
  Varying them needs a host whose lists can change (not done).
- zh-CN / zh-TW / ko have no ambiguous Path names (no shared word across titles): their `which` come from
  Step and Exercise names only.
- Local-model bulk paraphrasing (Qwen3-8B) not used: the helpers' 563 wordings a language with slot
  fills gave the size.
