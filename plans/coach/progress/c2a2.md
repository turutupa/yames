## Decisions and why

- **Listen on Jam too**, though the leg names Metronome, Drill and Setlist: on a computer the old Start was
  the only way to turn the input on in Jam, and "Hear what I play", jam recording takes and the `jam` tag on
  stretches all need it. Without Listen there, Jam would have lost them (tools lose nothing). DESIGN 3.1's
  Jam row (silent while the band plays; one line on stop) is c5a's to refine.
- **The line keys on this run**: a tip from the last run steps aside when the click starts again; the note
  shows only while stopped. Mount-keyed by tool, so nothing follows the player from one tool to the next.
- **Tool runs lists every stored session**, Path Sessions' included, as History did: the store does not
  mark where a row came from. The intro says so ("in the tools and in Sessions").
- **Tool runs is desktop-only** (the phone's tools have no coach; History never existed on a phone).
- **The rail's coach status** still says "In session" / "Listening" (it reads `session.active`).

## Where the design differs from the code

- DESIGN 7 "Loading the model: when Ask first needs it" is the selector's now (owner, ms1).
- DESIGN 7 says `messages` leaves `useSession`; it stays (c2a1): the line and note read it. c5c splits.
- The old History kept no generated summary; neither does Tool runs (a run's comment is Rust's).
- "14 coachCard keys": 11 were left when this leg started (c2a1 took 3); 6 go, 5 stay (`clearAll`,
  `today`, `yesterday`, `noteSpacingTrend`, `historyKeptInSettings`: still used).
