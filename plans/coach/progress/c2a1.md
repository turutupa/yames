## The `useSession.ts` diff, for the reviewer

`git diff coach..coach-c2a1 -- src/hooks/useSession.ts` (9 insertions, 180 deletions). Nothing reordered; only removals and three one-line replacements:

- **Removed:** `cardOpen` state; `toggleCard`; `sendChat` (the whole callback); `sendChatRef` and its sync effect; `messagesRef` and its sync effect (read only by `sendChat`); `chatInputFocusRef` / `registerChatFocus` (the old card's chat box is gone); the return keys `cardOpen`, `sendChat`, `toggleCard`, `registerChatFocus`; the imports that became unused (`resetCooldowns`, `detectStaminaPattern`, `formatPresetSummaryForLLM`).
- **Replaced:** `setCardOpen(true)` in a non-quiet `startSessionNow` → `showToolsCoach()` (the panel opens on the Tools coach section, as the card opened before); in `handleChipAction`, an LLM chip's `sendChatRef.current?.(chip.label)` → `askCoach({ question: chip.label })`, and `open-chat`'s `chatInputFocusRef.current?.()` → `askCoach()`.
- **Kept:** `messages` (the tools' feed: greeting, tips, mini-reports, chip answers, the end card) and everything that writes it. Hook order changes only by the removed hooks, consistently on every render.
- **Behaviour that went with `sendChat`:** a typed question no longer appends "User asked …" to the tools session's narrative and no longer resets the gatekeeper's cooldowns; its prompt is built from the coach's context (`contextForModel`) rather than the tools session's aggregate, preset history and narrative. A question asked with no tools session active used to be dropped silently (the session token's `isInactive`); it is now answered (or honestly declined).

## Decisions and why

- **`messages` stays in `useSession`.** The leg lists it with the panel state, but `messages` is the tools' feed (tips, reports, the greeting and end card, chip answers), written from twenty places inside the session hook. Moving it would have been a rewrite of the hook the reviewer guards, for a feed that c2a2 replaces with the tool's line and note. The conversation's turns live in `askStore` instead: that is the panel's `messages`.
- **The tools' coach is a section of Ask**, "Ask | Tools coach" in the head (where the mock's "Ask | Notebook" sits; c4a's Notebook can take the slot when c2a2 removes this one). It shows on the screens the old card was on (the tools, Today, Paths, Progress, Tools), never in a Session, on Songs or on a phone. Start opens the panel on it (`showToolsCoach`).
- **The answerer is the old chat, unchanged on the Rust side**: kind `chat`, its 15 s timeout, the same instruction sentence. Every model answer is labelled "General advice · not from your playing" (owner decision 3) with the c0 source line.
- **Focus:** the rail's row, the Session pill, `?` and a question put the caret in the box (desktop); `C` toggles without moving focus. While focus is in the panel every key stops there (the Session's keys are off); Escape closes it, also from outside the panel, before it means Exit.
- **`toggle-coach` on the Setlist and Songs** (the parity table's pinned gap 6.1 item 14) is closed on purpose: Ask is one panel on every screen but Settings.
- **The phone's selector** sits in the sheet's head (owner) and opens downward (new `placement` prop); on a phone it reads "not on this device".
- **"Looking at"** is built in an effect when the panel opens or the screen, the phase, the Exercise or the number of Takes changes; never in a render, never while a Take runs (the panel is not mounted).
